# CollectClock

🎯 Your daily source for sweepstakes and social casino bonus links

## About

CollectClock is a lightweight, mobile-friendly web app that helps you discover and organize daily bonus links for sweepstakes and social casinos. Access all your favorite casino bonuses in one place with an easy-to-use interface.

### Features

✨ **Dynamic Bonus Cards** - Browse daily bonuses from popular sweepstakes casinos  
🔍 **Smart Search** - Quickly find bonuses by brand name or keyword  
🌙 **Dark/Light Mode** - Comfortable viewing any time of day  
⭐ **Favorites** - Mark and filter your favorite brands  
📋 **Copy Bonus Codes** - One-click copying of promotional codes  
🔄 **Smart Sorting** - Sort by recently verified or brand name  
📱 **Mobile-First** - Fully responsive design optimized for all devices  
💾 **Offline Ready** - Works without internet after first load

- Pure HTML5, CSS3, and Vanilla JavaScript
